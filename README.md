THAKUR VIBE — mobile website demo

Files:
- index.html: responsive, single-file demo website

How to use on Android:
1. Download/extract the ZIP.
2. Open index.html in Chrome or a code editor with HTML preview.
3. To publish it online, upload index.html to a static host such as GitHub Pages or Netlify.
4. For a real public social app, add secure sign-in, database, media storage, moderation/reporting, privacy settings and age-appropriate safety controls. This demo does not publish posts or store likes on a server.
